# v2.8 上線步驟（照順序做）

v2.8 = **賽季進步追蹤（SPEC F8）＋ 出席率**：

- 球隊管理員在「管理專區 → 賽季」**開新賽季**：名單和帳號自動帶到新的一季，上一季封存（只能看）。
- 球員報告多了「**進步**」分頁：每季能力趨勢、各類別比上一季進步／退步、兩季雷達圖比較。同一個系列的隊友自動看得到。
- 「我的」和球員報告的進步分頁看得到**自己的出席率**（比賽、練習分開）；球隊管理員在「賽季」分頁看得到全隊，還有**全隊進步排行**。
- 舊賽季：頁面上方有橫幅；出席按鈕、發文框、能力表、「我的」編輯區都不能用；資料庫另外有守門員，任何寫入都會被擋。
- 選球隊頁：同一支隊伍的各賽季收成一張卡，舊賽季列在卡片下面。
- **隱私權政策更新、`POLICY_VERSION` = 2026-10-13**：隊友現在看得到你前幾季的能力自評，所以大家下次登入要重新同意一次。

`0012` 新增了：

| 東西 | 做什麼 |
|---|---|
| `teams.lineage_id`、`prev_team_id`、`archived_at` | 系列、上一季、封存時間（有值 = 舊賽季） |
| `players.prev_player_id` | 上一季的自己；只有 `start_new_season` 能設定 |
| `season_guard` 觸發器 | 掛在每張屬於球隊的表上，舊賽季一律不能新增、修改、刪除 |
| `start_new_season` | 開新賽季（球隊管理員）：複製名單、帶帳號、複製 Discord 設定、作廢舊管理員碼、封存舊賽季、可選通知 |
| `get_progress`、`get_team_progress` | 進步資料；前者同隊都能看，後者只有球隊管理員 |
| `join_team`（更新） | 用舊賽季的 Team ID 加入會回 `archived` |
| `export_my_data`、`delete_my_account`（更新） | 下載資料多了系列／封存時間；刪帳號可以清掉舊賽季裡自己的資料 |
