# v2.4 上線步驟（照順序做）

v2.4 = **組隊（F3）**：自動排陣容、拖曳／點選手動換人、鎖定重排、替補名單、
官方陣容（全隊看得到）和個人草稿、不用登入的分享連結、陣容圖片下載（PNG）。

## 1. 資料庫（已完成 2026-10-07）

- [x] Supabase → SQL Editor 執行 `supabase/migrations/0007_lineups.sql`
- [x] 執行 `supabase/tests/rls_test.sql`，最後出現 `RLS OK`

`0007` 新增了：

| 東西 | 做什麼 |
|---|---|
| `lineups` 表 | 一支球隊的陣容：官方（`kind='official'`，全隊看得到）或草稿（`kind='draft'`，只有自己看得到） |
| `save_lineup` | 新增／更新陣容；草稿只能改自己的，官方只有球隊管理員能改 |
| `delete_lineup` | 刪除陣容，規則跟上面一樣 |
| `set_lineup_share` | 開關分享連結、是否顯示名字、重新產生連結（舊連結失效） |
| `get_shared_lineup` | 唯一一個**不用登入**（anon）就能呼叫的函式：只回傳背號和位置，不會回傳球員 id、能力分數、是誰排的 |
| `export_my_data` / `delete_my_account`（更新） | 下載資料多了陣容；刪帳號會刪掉自己的草稿（官方陣容保留，但擁有者欄位清空） |

只新增東西，不會動到現有的球員和能力表。

## 2. 本機測試

在 VS Code 終端機（PowerShell 擋 `npm` 的話，改打 `npm.cmd`）：

```
git switch v2.4
py -m pytest
cd web
npm.cmd run typecheck
npm.cmd test
npm.cmd run dev
```

用 Chrome 打開 http://localhost:3000，登入一般球員帳號，再登入球隊管理員帳號各測一次。

### 桌機

- [ ] 組隊頁：切換 11 人制／8 人制、切換陣型，人員盡量留在原位置
- [ ] 自動排：門將一定排到、人數不夠時缺的位置會列出來
- [ ] 點兩個位置互換；拖曳球場上的人到另一個位置互換；拖曳替補名單的人到球場上的位置
- [ ] 鎖定某個位置後按「自動排」，鎖定的人不會被換走
- [ ] 點位置看「為什麼是他」（適合度、自評擅長／不擅長），下面的候選名單可以直接點著換人
- [ ] 球隊管理員：存官方陣容，一般球員登入也看得到；存草稿，只有自己看得到、別人看不到
- [ ] 一般球員：只能存自己的草稿，不能存官方陣容（畫面上不會有官方／草稿的切換）
- [ ] 刪除陣容（要先按「刪除」再按「確定刪除？」才會真的刪）
- [ ] 分享：開啟分享連結、複製、用無痕視窗（不登入）打開連結看陣容——只看到背號和位置，看不到分數
- [ ] 分享：開啟「顯示名字」後連結和下載的圖片會顯示姓名；關掉只顯示背號
- [ ] 分享：「重新產生連結」後舊連結打開要失效
- [ ] 下載陣容圖片（PNG），打開確認球場、背號、標題都正常

### 手機（390 寬）

F12 → Ctrl+Shift+M → 選一台寬 390 的手機 → F5。

- [ ] 球場圖不會橫向捲動，位置框的字看得清楚
- [ ] 手機上用「點一個、再點一個」互換（拖曳在手機上不好用，確認點選方式可以完全取代）
- [ ] 替補名單、候選名單可以正常滑動、點擊
- [ ] 分享面板、下載按鈕排版正常
- [ ] 最好用真的手機再看一次（手機連不到 localhost，要等合併上線後用正式網址看）

### 有真實資料後再看

- [ ] 全隊都填過能力表之後，自動排的結果是否合理
- [ ] 分享連結分享到 LINE／IG 實際看圖片顯示效果
